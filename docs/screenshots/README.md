# Screenshots

Put public, sanitized project screenshots in this folder.

Suggested filenames:

- `homepage.png`
- `showroom.png`
- `vehicle-gallery.png`
- `booking-modal.png`
- `profile-orders.png`
- `support-chat.png`
- `admin-dashboard.png`
- `news-page.png`

Before committing screenshots, hide or blur:

- emails, names, phone numbers, and user IDs;
- JWTs, admin setup tokens, API keys, OAuth secrets, and refresh tokens;
- database hosts, passwords, and private URLs;
- Google client IDs, Drive folder IDs, and credential filenames;
- any visible `.env` values or browser devtools network headers.
